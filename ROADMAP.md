# Roadmap

This alpha adapter starts with read-only resource inventory through the provider inventory API.

## Direction

- Establish conformance with the `orbit-cloud` contract.
- Validate client lifecycle, cursor handling, permissions, partial results, timeout, and failure behavior.
- Add broader scope coverage after live non-production validation.
- Consider provider-native language variants only when a concrete workload and evidence justify maintaining them.

No release dates or production support guarantees are implied.
